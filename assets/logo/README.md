# JSPI logo assets

The wordmark recreates the owner's selected concept 4, “Scalpel Underline”: serif JSPI lettering above a suture line that joins a horizontal scalpel. It is a new vector interpretation of the supplied concept, not an identical vector extraction of the raster source.

- jspi-logo.svg — burgundy mark for ivory/light surfaces.
- jspi-logo-ivory.svg — ivory mark for slate/dark surfaces.
- jspi-logo.png and jspi-logo-ivory.png — 1040 × 616 transparent exports.
- favicon.svg, favicon-32.png, apple-touch-icon.png — a simplified J and suture underline derived from the wordmark identity.

The main SVG lettering uses outlined Libre Caslon Display glyphs, so the logo has no external font dependency. Display lettering is covered by the SIL Open Font License included under assets/fonts/display-license.txt. The scalpel and suture geometry were drawn specifically for this project. Preserve the SVG viewBox and aspect ratio when resizing.
